# Aventura Azul

Página informativa de **Aventura Azul**, una plataforma educativa para niñas y niños con TEA (trastorno del espectro autista).

- Página: https://olgadanzuniga-dotcom.github.io/aventura-azul/
- Descarga de la demo para Android: [Releases](https://github.com/olgadanzuniga-dotcom/aventura-azul/releases/latest)

La página está en español, inglés, portugués y francés (`i18n.js`).
